# Decisões

- Manter a stack estática e remover dependência de JavaScript para links de serviço.
- Separar estilos e interações, sem framework ou processo de build desnecessário.
- Manter o noindex da demonstração. Não alterar domínio nem publicar nesta tarefa.
- Usar o perfil fornecido como fonte primária do endereço; diretórios têm dados conflitantes. Registrar fontes.
- Não ocultar conteúdo com IntersectionObserver: a página deve ser utilizável sem JavaScript.
- Fotografias documentais, sem filtros de cor que alterem a apresentação do acabamento.
