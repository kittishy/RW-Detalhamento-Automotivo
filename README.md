# RW Detalhamento Automotivo

Site demonstrativo não oficial para RW Detalhamento Automotivo (Santa Rosa, RS).

## Como editar

Abra `index.html` no VS Code. O site é HTML/CSS/JavaScript estático, sem instalação de dependências. Para testar localmente, use uma extensão de servidor local ou `python -m http.server 8080`.

## Publicação atual

https://rw-detalhamento-automotivo.vercel.app/

## Antes da entrega oficial

- Substituir as imagens ilustrativas externas por fotos autorizadas dos trabalhos reais da RW.
- Confirmar informações e serviços junto ao cliente.
- Revisar links, formulário e comportamento em telas pequenas.
- Remover `noindex` e atualizar `robots.txt` somente após aprovação do cliente.

O deployment atual na Vercel foi feito diretamente com arquivos; mudanças neste repositório ainda não estão configuradas para disparar deploy automático.
